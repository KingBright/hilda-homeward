# 《希尔达 · 黄昏的回声：归途》
### Hilda: Echoes of Dusk - Homeward

> 基于经典动画《希尔达》（Hilda）世界观精心打造的横版叙事解谜探索网页游戏。  
> 采用纯原生 HTML5 Canvas 与 Web Audio API 纯代码程序化合成技术，零外部素材依赖，单文件即开即玩。

## 📖 故事背景

特罗尔堡（Trolberg）的黄昏悄然降临，古老的城墙外迷雾翻涌，机械水钟的节拍在雨夜中低沉回荡。希尔达、小狐鹿枝枝（Twig）与挚友大卫（David）、芙丽达（Frida）被困在归途的迷津中。

为了穿过雨中的北门、唤醒沉睡的回流水泵、修复摇摇欲坠的木桥，并解开古老钟楼与巨魔岩山的秘密，希尔达必须借助同伴的智慧、生活中的物理常识以及随身的小物件，一步步解开谜题，在晨曦破晓前回到妈妈身边温暖的壁炉旁。

## ✨ 核心特色与技术亮点

### 1. 纯原生零外部依赖架构 (Zero-Dependency Single File)
- **极速轻量**：没有引入庞大的游戏引擎或外部庞杂依赖，没有外链图片、外部音频或外部字体。
- **纯 Canvas 2D 矢量与骨骼动效**：所有角色、场景建筑、动态树木、光影天气、雨滴水纹均由纯 JavaScript 代码实时绘制，在任何设备与高刷屏上均呈现清晰细腻的矢量质感。

### 2. 人体工学真实比例重构
- **严谨的身形比例**：恢复希尔达（~211px）、妈妈 Astrid（~270px）、大卫与芙丽达的绘本黄金身高差（1:1.28 母女比例）。
- **家具与场景基准协同**：客厅壁炉台面、书桌与茶几高度契合真实视线与手肘位置，彻底告别“主角比桌椅还矮”的失真感。
- **同伴跟随避让**：优化同伴（大卫、芙丽达）与萌宠枝枝的跟随算法与安全间距，行走自然且不再重合穿模。

### 3. 环环相扣的物理逻辑与谜题设计
拒绝不符合常识的“隔空取物”与“数值拼凑”，所有互动均具有现实物理与机械因果支撑：
- **牵引套索与弹性形变**：树枝上的高空铁钩无法空手拾取，必须先拾取旧绳圈向树藤抛掷套索；大卫在下方协助牵引拉弯树枝，希尔达摘下铁钩后树枝弹性复位，自然合成带钩绳索。
- **双态动态地面函数**：修复林间木桥后，角色脚步吸附函数动态切换至桥面木梁标高，过桥时稳稳踏在木板横梁上，彻底解决踏水穿模。
- **高空检修长挑杆**：水道清障捞出工程用长柄挑杆后，才能拨动天花板高处的转动活节。
- **重物借力与缓冲机制**：钟楼大齿轮借助石阶斜坡杠杆推入轴槽；巨钟钟舌则踩上石基垫入羊毛毡消音。

### 4. 纯代码 Web Audio API 动态双轨音景 (Soundscape)
无需加载任何外部 MP3/WAV 资源，完全由浏览器实时振荡器与滤波器动态生成：
- **12 幕专属自适应背景音乐（Generative BGM）**：
  - *第 0 幕（温暖客厅）*：C 大调暖心五声琶音，木质拨弦治愈感；
  - *第 1 幕（雨中北门）*：D 多利亚调式清冷雨幕与探索动机；
  - *第 2 幕（回流水泵）*：A 小调潮湿地下空灵回响；
  - *第 3 幕（神秘钟楼）*：F 利底亚调式高耸石壁旋律；
  - *第 4 幕（水钟心脏）*：G 大调机械音步与节拍卡点；
  - *第 5 ~ 11 幕*：潜行低音、古城遗迹神秘减和弦、屋顶暴风雨紧张切分直至晨曦大七和弦解脱升华，场景切换自动平滑淡入淡出（Cross-fade）。
- **程序化环境音效（Physical Ambience）**：
  - 基于 3 秒 Pink Noise 粉噪循环缓存，配合 0.2Hz LFO 调制出呼啸阵风、高通滤波雨幕、带通流水潺潺、壁炉低频火声与 1 秒周期精密钟摆机械秒针滴答。
- **角色专属语音伴音（Speech Blip）**：
  - 希尔达（560Hz 清亮颤音）、妈妈（230Hz 暖正弦低音）、大卫（390Hz 怯生管音）、芙丽达（490Hz 晶莹纯净方波）、枝枝（760Hz→860Hz 鹿狐滑音啾叫）等。

### 5. 对话打字机系统与顺畅快进
- 文本以 28ms 节奏逐字跳出，遇到标点自动微停顿 85ms，带来生动呼吸感；
- 随时点击对话框任意区域或按 `空格` / `回车` 键即可瞬间展示整句完整文本，再次点击即可翻页，操作丝滑不拖沓。

## 🎮 操作指引

| 操作项 | 键位 / 控制方式 |
| :--- | :--- |
| **左右移动** | 键盘 `A` / `D` 或 `←` / `→`，或直接鼠标点击地面指引走动 |
| **调查 / 拾取 / 互动** | 鼠标左键点击场景中的人物、高亮道具或机械装置 |
| **道具使用与组合** | 点击底部道具栏选中道具（高亮浮起），再点击场景目标或另一个道具进行组合 |
| **对话推进 / 快进** | 鼠标点击对话框，或按下键盘 `Space` / `Enter` 键 |
| **音效开关** | 首次点击画面唤醒 Web Audio 引擎，右上角提供快速静音切换 |

## 🚀 本地运行与测试

因为本项目为标准零依赖静态应用，你可以选择以下任意方式运行：

### 方式一：直接双击打开
直接在文件管理器中双击 `index.html`，使用现代浏览器（Chrome、Edge、Safari、Firefox）打开即可直接游玩。

### 方式二：使用本地静态服务器（推荐）
```bash
# 使用 Python 快速启动
python3 -m http.server 8080

# 或使用 Node.js serve / http-server
npx serve .
```
在浏览器中访问 `http://localhost:8080`。
