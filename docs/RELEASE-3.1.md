# V3.1 雨夜精修

## 体验入口

本轮变化集中在北门、森林和水泵。已有进度不会清空，越过这段的存档也不会强制返工。体验全部新演出可先导出原进度，再从新冒险进入；主线可回访的地点仍可返回调查。

## 新的因果链

北门：走近拉雨棚 → 拾取曲柄 → 安装曲柄 → 三次转动逐格抬门。

森林：取绳 → 弯枝取得钩子 → 合成并投出绳钩 → 请大卫稳住制动 → 转动绞盘升桥。大卫的站位不会越过未修好的桥，也不遮住地上的绳。

水泵：关进水闸 → 清滤网并取得挑杆 → 接管 → 重新开进水闸 → 观察连通和漏点 → 试压。可以先在干管状态接管，但不能闭闸启动水泵。开始运行后不能带压拆接头。

## 框架约定

点按、拖动、键盘、背包投放必须共用走近与操作路径。准备和接触动作不写入永久进度，完成才一次性提交。菜单和后台暂停时间轴，取消、重开、跳场景必须撤销未完成动作。存档协议仍是 V3，旧完成状态保留。

新拆分模块包括动作时间轴、双段逆运动学、角色骨架、动作编排、共享台面轮廓和章节景物演出。没有加入运行时联网依赖，发布仍是单个 HTML。

## 范围限制

本轮没有新增章节，没有完整配音或手工逐帧动画，不代表获得 Hilda 商业授权。程序化美术、剧情节奏、后半段专用表演、真实手机和多浏览器验收仍需继续打磨。单元与浏览器测试报告只是对应代码行为的证据，不是商业品质认证。
