## 可见的变化

档案室用轨道与书脊对应的索引引导定位，再锁轮攀爬。主角推梯时跟随梯子移动，上梯后够取档案并原路下梯。木轮刹车、书脊标签、归还箱和维护留言补充场景细节。

屋顶先固定锚点，再拉回大卫；再次请大卫帮忙，他沿安全路径到支点旁。长挑杆抬梁、同伴撤离、枝枝跳回身边和共同登上沃夫都沿同一个可暂停动作时间轴执行。检修轮移到可触及位置，驱动高处光轴。档案中「先稳住，再伸手」的留言在救援时得到回应。

## 保住玩家已经做对的事

风暴检查点只让队伍退到安全位置并清空压力，不撤销已经救回的同伴或拆掉已固定的绳索。未使用的绳索只恢复一份。长挑杆继续可重复使用。所有人齐全才允许离开。

梯子与信标拖动使用临时预览，不再直接修改存档。取消手势、菜单、窗口失焦、页面隐藏都会清除预览。未完成的攀爬、系绳或抬梁不会提前发奖或消耗道具。

## 结构与验证

新增场景共同规则、纯演出采样与独立美术层三个模块。`work` 可接收第四个参数覆盖动作编排，不能写入永久进度。最终状态仍只在完成回调提交。

单元测试覆盖停靠、刹车、动作提交、救援前置条件、可复用工具、检查点、旧存档迁移和整个演出时间段的有限坐标。浏览器完整流程另外验证菜单暂停、中途重载、拖动取消、两类输入预览不写存档、触屏及减少动态。报告带实际发布 HTML 的 SHA-256，不用旧测试代替本次验收。
