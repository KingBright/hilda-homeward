# V3.6 同行的呼吸

## 枝枝

枝枝的身体从固定 SVG 路径拆为四条腿、蹄、躯干、头、耳朵、眼睛和尾巴。上腿与下腿保持固定长度，落地时保留世界空间接触点，换步时才移动蹄。较慢的步行逐腿迈步，小跑使用对角支撑组；停下后补完最后几步，不再原地持续踏步。

跟随不再将整张图按指数平移，也不直接复制主角的左右朝向。枝枝有自己的速度、加速、制动、停止区间与短暂的收步转向。主角只是转向物品或说话时，枝枝不立刻绕到另一侧。转身仍是带预备过程的风格化二维侧向切换，不是三维绕身动画。

地形倾斜会影响躯干和脚的求解；场景重新摆位、读档与屋顶检查点恢复会重置接触缓存，避免新站位拉扯旧脚印。屋顶登船采用原有剧情位移并收腿，不在空中播放普通地面跑步。

站住时，枝枝在安静间隔中偶尔嗅闻、抬耳听声，配合不同步的耳朵、眨眼、尾巴与呼吸；对白时收敛嗅闻，转向注意同伴。减少动态模式关闭这些循环，暂停冻结当前姿势和跟随位置。

## 人物

静态人形角色分出上身与固定脚部。大卫扶包带，芙丽达整理围巾，妈妈轻微摊掌，不同人使用不同节奏和相位，动作之间有真正的静止间隔。细小的上身重心、呼吸和视线变化不带着脚整体漂移。

工作和待机有明确优先级：桥梁制动、屋顶支撑、水钟协作与主角机关动作优先，普通待机手势不抢占支点。原有舞台 / 头像文字驱动口型仍保留，眨眼统一由同一层控制以正确暂停。

可操作希尔达的四肢仍由 `art/performer` 的接触骨架控制，本轮共享眨眼和视线变化，不新增其全部站立手势。阿尔弗、巨魔和沃夫保留原有造型与次级动画，不声称本轮已为所有生物完成骨架重做。

## 模块与工作台

- `engine/animal-life.js`：独立跟随、脚底接触、地形姿态和停步表演。
- `art/twig-design.js` / `art/creature-life.js`：共享动物造型与真实场景渲染。
- `engine/idle-life.js`：可重复采样的角色待机习惯；不写入剧情和存档。
- `art/cast-acting.js`：处理表演优先级、手部、重心、视线和眼睛。

`tools/cast-studio.html` 使用同一份源码，新增枝枝的慢走、小跑、停步演示。关闭「对白演示」可以检查人物独立待机；暂停和减少动态同时作用于人物与动物。

## 检查方法

```sh
npm run check
export CHROMIUM_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
.venv/bin/python tests/life.py
.venv/bin/python tests/playthrough.py
.venv/bin/python tests/body-motion.py
.venv/bin/python tests/acting.py
.venv/bin/python tests/cast-studio.py
.venv/bin/python tests/art-audio.py
.venv/bin/python tests/native-storage.py
```

新增单元测试覆盖固定骨长、慢走与小跑的支撑接触、帧率变化、反向、斜坡、停止、重置、暂停和人物习惯。浏览器专项实际点击移动，读取渲染后蹄子的世界坐标。只比较同一接触编号内的支撑帧，避免将跳过的完整迈步误记为滑步。另有明确标注的独立表演测试场验证待机、镜像、支撑优先级和减少动态，它不是另一遍完整通关。

主通关与表演专项使用显式的内存存储适配器；原生 HTTP/file 存储和 NAS HTTPS 刷新分别测试。新专项结果在 `previews/v3.6/life-report.json`，各报告均需核对当前构建 SHA-256。旧文件名目录中的回归报告只有哈希一致才有效。

## 发布边界

这是风格化二维关节动画，不是物理动物仿真、完整自主行为系统或三维动作捕捉。自动化接触、时序与通关检查不代替审美试听、真实手机、Safari / Firefox 或低端性能验收。

沿用 `bash deploy.sh` 的受检发布流程：旧版备份、上传校验、单文件原子替换、公开 HTTPS 字节校验；随后用 `tests/nas-smoke.py` 检查实际线上跟随、拿取与原生存档。V3 存档键和剧情条件不变，无需删除玩家已有进度。
