# V3.9 连贯的归途

本轮接续此前尚未提交的十二幕优化，保留游戏独立源码、离线单文件产物和原来的谜题流程。

- 家中与归家：窗光对齐窗框，人物、热茶和手记托架各有位置；拥抱使用可完成的动作过程。
- 北门、森林与档案室：调整交谈和观察站位、图纸的出现时机，丰富各自的环境观察物。
- 水泵与升降站：清理滤网时收起长杆，区分救援绳与普通绳；配重拖动使用自身外形，吊盘实物、点击范围与动作接触点共用几何。横梁绕支点倾斜，配重可拖回地面。
- 避风处与钟楼：逐个敲击回声石；齿轮对位、开门、旁路泄压和排洪飞轮使用连续反馈。门扇限制在门洞内，仪表的中间读数保留到下一次操作。
- 屋顶与山脊：同伴完成支撑后恢复手臂并退开；灯罩的转动姿态在完成与读档后保持一致；母子团聚使用局部坐标与共同的端点，希尔达沿坡道连续陪行。
- 全局：背侧手臂置于躯干后，调整枝枝和小巨魔的轮廓，标题界面隐藏玩家与游戏按钮。

所有新增演出沿用可暂停、可取消的动作时间轴，完成前不提交物品和剧情标记。存档结构、物品协议和十二幕结局未改变。

验收使用 `npm run check`、完整浏览器通关及相关专项回归。`tests/scene-continuity.py` 专门比较机关动画端点与提交后的真实 SVG 坐标，并验证团聚中途暂停、重载与配重拖动。报告写入忽略的 `previews/v3.9/`，记录被测 HTML 的 SHA-256。浏览器触控模拟不代表真机验收，也不替代玩家对美术和节奏的评价。

本轮验收结果：119 项代码检查、159 项完整通关及回归检查全部通过；8 组游戏专项共 173 项检查通过，9 份游戏报告均对应最终构建的 SHA-256。角色工作台另有 23 项检查通过，并核对了共享源码哈希。已逐幕复查十二幕画面及标题页。
